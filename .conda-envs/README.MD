This directory contains 3 platform-specific environment files:

* linux.txt
* macos.txt
* windows.txt

These will be used when you use the DIALS bootstrap. Please see
https://dials.github.io/documentation/installation_developer.html
for instructions.

Temporary 9/1/2026: a 4th file osx-arm64.txt is provided with platform-
specific compilers for Apple silicon. This will be removed when an upstream
bug (boostorg/boost#1107) is fixed.
